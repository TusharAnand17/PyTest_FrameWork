User Story
As a user filling out a preference form
I want to select my gender, preferred days, country, and favorite colors
So that my preferences are accurately captured and stored in the system

Acceptance Criteria
- Gender section shows Male and Female radio options
- Gender options are unselected by default and mutually exclusive
- Days section shows all 7 weekdays as checkboxes
- Days are unselected by default and can be checked independently
- Country section shows a dropdown with United States pre-selected
- Country can be changed and current selection is displayed
- Colors section shows multi-select options including Red, Blue, Green, Yellow
- Colors are unselected by default and support select, scroll, and deselect
- Selections persist across sections until changed
- Submission captures and stores selections accurately
- Required fields (if configured) must enforce at least one selection

Positive Scenarios
PS-01: User views preference form and sees all sections with expected default states.
PS-02: User selects one gender and verifies only one option remains selected.
PS-03: User selects multiple days and toggles individual days independently.
PS-04: User keeps default country or changes country and sees updated selected value.
PS-05: User selects multiple colors, sees visual indicators, and deselects selected colors.
PS-06: User interacts across sections and previously selected values remain unchanged.
PS-07: User submits completed preferences and system captures all selected values.

Negative Scenarios
NS-01: User submits form with no selection in a required field and sees validation feedback.
NS-02: User attempts submission with inconsistent required configuration and submission is blocked with clear guidance.

Edge Cases
EC-01: User leaves all optional sections unselected and form state remains stable.
EC-02: User selects all days and no days in separate interactions and both states are supported.
EC-03: User scrolls long color list and selects options near the end of the list.
EC-04: User repeatedly changes gender selection and latest value is retained.

Validations
VAL-01: Gender behaves as mutually exclusive radio options.
VAL-02: Days behave as independent multi-select checkboxes.
VAL-03: Country dropdown shows selected value accurately after change.
VAL-04: Colors multi-select shows selected and deselected states clearly.
VAL-05: Cross-section interactions do not clear unrelated selections.
VAL-06: Submission payload contains all current selections accurately.
VAL-07: Required-field validation triggers only when required fields are empty.

Boundary Conditions
BC-01: Minimum selection boundary is one option for each required field.
BC-02: Maximum day selection boundary supports all seven days selected.
BC-03: Maximum color selection boundary supports all available colors selected.
BC-04: Zero-selection boundary supports no selected days and no selected colors when optional.
